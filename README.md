# مشروع بلدية المغازي (Maghazi Municipality)

يقدم هذا المشروع المنصة الإلكترونية الخاصة بـ **بلدية المغازي**، والتي تهدف إلى تسهيل التواصل مع المواطنين وتقديم الخدمات البلدية بشكل إلكتروني وفعال.

---

## 🔗 رابط المشروع

يمكنك زيارة موقع المشروع مباشرة من خلال الرابط التالي:

👉 **[موقع بلدية المغازي الإلكتروني](https://marahalladin3-pixel.github.io/maghazi-municipality/)**

---

## 📌 نبذة عن المشروع

تُعد هذه المنصة واجهة إلكترونية حديثة لبلدية المغازي، صُممت لتغطية عدة جوانب أساسية:

1. **التعريف بالبلدية:** تقديم رؤية ورسالة البلدية وأهدافها في خدمة سكان مخيم ومدينة المغازي.
2. **الخدمات الإلكترونية:** إتاحة الوصول إلى الخدمات المعاملاتية والاستعلامات الإلكترونية للمواطنين.
3. **الأخبار والإعلانات:** نشر أحدث الأخبار، التنبيهات، والإعلانات المهمة المتعلقة بالخدمات العامة والمشاريع الحالية.
4. **التواصل والدعم:** توفير قنوات تواصل مباشرة بين المواطنين وإدارة البلدية لتقديم الشكاوى والمقترحات.

---

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3:** لبناء الواجهات وتصميم استجابة الصفحات لجميع الشاشات (Responsive Design).
- **JavaScript:** لإضافة التفاعلية وديناميكية الاستخدام.
- **GitHub Pages:** لاستضافة الموقع وإتاحته بشكل مباشر عبر الإنترنت.
